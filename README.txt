ヤシマ作戦クロック（共有サーバー用 PHP + HTML + JS）
================================================

【アップロード】
1. ZIP を解凍する
2. 中のファイル一式を public_html（またはサブフォルダ）へ上書きアップロード
   ※ 特に ntp.php と assets/app.js は必ず更新してください
     （英国などタイムゾーンの違うサーバーでも、時刻が1時間ずれないようにしました）
3. data フォルダを書き込み可能にする（パーミッション 755 または 777）
4. ブラウザでその URL を開く（キャッシュ対策で再読み込み）

必要なファイル:
  index.php
  ntp.php
  clock.ini
  lib/counter.php
  data/hits.txt     … アクセス数（自動で増えます）
  data/.htaccess
  assets/app.css
  assets/app.js

【NTP サーバの変更】
clock.ini の server = を書き換えて保存し、再読み込み。
NTP は「絶対時刻」だけをブラウザに渡します。サーバー自身の時計（英国なら1時間ずれやすい）は使いません。

【アクセスカウンター】
ページを開くたびに data/hits.txt が増えます。右上 COUNT に表示。
増えない場合は data フォルダの書き込み権限を確認。

【フォント】
fonts フォルダに .woff2 / .woff / .ttf / .otf を置くと、その字体で表示します。
  display.ttf     … 見出し・本文
  mono.ttf        … ファイル名に mono が含まれると時刻まわりの等幅
何も置かなければ、端末の日本語フォントのままです。
